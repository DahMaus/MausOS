# MausOS

A browser based OS featuring 2 apps, music and a live background :D
## Showcase

![MausOS demo](./ShowCaseMausOS-2(1).gif)

## Try it out

[**Launch MausOS**](https://dahmaus.github.io/MausOS/)

## Features

- **Swagyrator**: A bare bones cookie clicker clone
- **My Games**: My on Itch.io hosted gamejam games :D
- **Music** Enjoy the crunched down wii music lol
- **Live Wallpaper** It's a beautiful mountain!

## Run locally

1. Clone this repository
2. Open `index.html` in your browser
3. Enjoy the swag :D
